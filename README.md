# 随身私房菜谱 (My Pocket Kitchen) · 料理手账风

专为手机与日常下厨打造的**温馨手绘风 / 料理手账本纯离线个人菜谱系统**。采用暖色手工纸张底纹、绘本墨水描边、和纸胶带与私房朱砂印章设计，不依赖任何外部网络，手机与电脑皆可顺畅使用，支持添加到手机主屏幕如同原生 App 般体验。

---

## 🌟 核心特色与功能

1. **🎨 温馨复古手绘风 & 料理手账本视觉设计 (全新升级)**
   - **手绘手账质感**：暖色方格纸底纹、手工绘本墨水线（Organic Sketch Lines）与硬立体墨影。
   - **和纸胶带与私房印章**：卡片与板块缀有半透明彩绘和纸胶带（Washi Tape）与朱砂红【手作】、【私房】、【旬味】印章。
   - **水彩晕染光晕**：菜品图标配备柔和水彩光晕，食材按钮采用木刻印章质感，按压带有弹性质感。
   - **手账笔记清单与便利贴**：详情页采用真实横线笔记本设计，烹饪秘诀采用黄色大头针便利贴呈现。

2. **📱 手机原生级交互 & 100% 纯离线运行**
   - 采用移动端优先（Mobile-First）设计，底部手账书签导航栏、丝滑抽屉动画、触摸震动与声音反馈。
   - **零外部网络依赖**：图标、音频（Web Audio API）、二维码生成（本地 JS）、菜谱数据均本地内置，断网也能秒开。
   - **支持 PWA「添加到主屏幕」**：在手机上可一键添加到桌面，以全屏独立 App 方式打开，摆脱浏览器地址栏。

3. **📖 经典菜谱库与精细图文做法（预置 92+ 道高分名菜）**
   - 官方深度内置 **92 道经典高分名菜**（涵盖湖南辣椒炒肉、农家一碗香、小炒黄牛肉、擂椒皮蛋、麻婆豆腐、鱼香肉丝、宫保鸡丁、糖醋里脊、地三鲜、经典回锅肉、水煮肉片、辣子鸡、老北京葱爆羊肉、清蒸鲈鱼、开胃酸菜鱼、辣炒花甲、剁椒鱼头、玉米排骨汤、西湖牛肉羹、本帮腌笃鲜、罗宋汤、冬阴功海鲜汤、丝瓜炒蛋、白灼菜心、广式腊味煲仔饭、扬州炒饭、漏奶华、葡式蛋挞、西米露等）。
   - **回到顶部浮标**：页面右下角贴心提供手绘微圆浮标，一键顺滑回顶。
   - **智能用餐人份换算器**：选择 1 人份、2 人份或 4 人份，所有食材分量、调料配比自动实时等比换算！
   - **手账备菜打勾清单**：食材清单支持点击划线标记，做菜井井有条。
   - **步骤详解与厨房定时器**：每道步骤包含火候秘诀，支持一键开启步骤倒计时闹钟。
   - 支持自由**录入、编辑与收藏**属于自己的私房自创菜谱。

4. **🛎️ 「饭店点菜模式」专属定制小票（支持按分类点选收藏私房菜）**
   - 顶部右侧新增 **【点菜】** 按钮，点击一键唤起专属点单台；
   - **分类清晰**：自动根据家常小炒、硬菜大餐、快手减脂、营养靓汤、懒人主食等分类呈现；
   - **专属点单**：点菜列表专为呈现您平时**「❤️ 我的收藏」**中的私房招牌菜，支持增减份数；
   - **生成手绘菜单小票**：自动核算总道数与预计烹饪总时长，一键生成带朱砂红章【主厨已接单】的手绘小票，支持一键复制菜单文本发送到微信群！

4. **🧊 「冰箱食材查菜」智能测算引擎（支持手动输入 + 120+ 丰富食材）**
   - 解决“冰箱里剩了这些，到底能做什么菜”的日常难题。
   - **✍️ 支持手动输入任意食材**：无论多小众的食材都可以直接键入（支持回车、空格或逗号批量录入），系统自动记录到您的常用食材库。
   - **超全固有食材库已扩充至 120+ 样**：覆盖肉禽蛋品、时令蔬菜、菌菇豆品、水产海鲜、粮油主食、调味常备等。
   - **智能同义词与模糊匹配**：如输入“番茄”能智能匹配“西红柿”，输入“大虾”智能匹配“鲜虾仁”等。
   - 自动按匹配度（如 **✨ 完美 100%**、**仅差 1 样**）智能排序，并高亮标出缺少的食材。

5. **🎯 「今天吃什么」油画棒手绘幸运大轮盘（支持自由增删候选项）**
   - 解决纠结症与选择困难症，采用柔和油画棒扇区配色与手绘墨线指针，**支持自由添加、删除转盘候选项**（不仅能放家常菜，还能添加火锅、麻辣烫、炸鸡外卖等任意选项）。
   - 提供**一键快捷预设**：支持“🎲 随机换一批 (菜谱库)”、“🍔 热门外卖选项”、“🥗 轻食减脂预设”以及一键清空。
   - Canvas 流畅物理减速旋转与中奖庆祝彩带特效，若抽中菜谱库已有菜品可一键直达详细图文做法。

6. **💾 本地数据隐私与一键备份迁移**
   - 菜谱与个人收藏均保存在本地存储（LocalStorage）。
   - 提供 JSON 一键导出与导入恢复功能，换手机随时迁移，安全放心。

## 🚀 手机与电脑使用方式

### 方式一：手机访问与添加到主屏幕（最推荐）

1. 确保手机与电脑连接在**同一个 Wi-Fi 或热点**下；
2. 双击运行当前目录下的 **`启动手机局域网访问.bat`**；
3. 电脑会自动弹出引导网页并展示**专属二维码**；
4. 打开手机相机或微信**扫一扫**，即可在手机上秒开菜谱；
5. **添加到主屏幕（实现像原生 APP 一样离线使用）：**
   - **苹果 iPhone (Safari)**：点击屏幕底部中间的“分享”按钮（带箭头的方框）➔ 往下滑动选择**「添加到主屏幕」**；
   - **安卓手机 (Chrome / 微信 / 自带浏览器)**：点击右上角菜单 `...` ➔ 选择**「添加至主屏幕」**或**「安装应用」**。
   - 添加后，手机桌面会出现“私房菜谱”独立图标，此后即使电脑关机、手机没有网络，也可直接打开离线使用！

### 方式二：电脑端直接运行

- 直接双击当前目录下的 **`index.html`**，即可在 Chrome、Edge 等现代浏览器中直接运行。
